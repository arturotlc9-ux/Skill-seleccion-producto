# Familia KSC-5X – Prensa céntrica manual KONTEC KSC-5X para 5 ejes

Fuente: catálogo KSC-5X (neerlandés; descripciones traducidas al español). 128 IDs validados contra el
PDF; 92 se comparten con KSC3/KSP3 (mordazas de sistema y superiores del grupo 125, topes, pines).

## Modelos

`KSC-5X 125-<longitud>-<altura>`: longitudes 320, 400, 500, 600, 800 y alturas 142, 181, 252 mm
(15 prensas). Ancho 125 mm, fuerza máx. 40 kN, par máx. 130 Nm. No existe versión grip.
Se entrega sin llave, sin mordazas y sin extensión de husillo.

**Siempre pregunta la longitud y la altura** si el usuario no las da completas (el script muestra
las 3 alturas cuando solo se indica la longitud).

## Mordazas superiores (GB*)

Interfaz W-125-1. **No hay portadora por defecto:** si el usuario pide una mordaza superior,
pregunta sobre cuál mordaza de sistema va montada:
SGWB-G3-B 125-66-40 (0432490) o SGWB-G3-B 125-59-40 (0430387), Qty 2. Las mordazas superiores W-65-1
no aplican (su portadora es la SG5A-B 65, de 5 ejes). Las GB* se cotizan como set de 2 piezas (Qty 1).

## Otros a pedido

## Notas del catálogo

- SGVA-B 125-25-57 (prisma vertical) solo está indicada para la KSC-5X 125-320.
- SPC 40 está indicado para 500, 600 y 800, pero no se ofrece por regla del usuario.
- Husillos: con el husillo estándar se obtiene el rango de sujeción mínimo; con el GSBG de la
  longitud de la prensa, el máximo.
